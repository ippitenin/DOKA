Нажимаете глобальный хоткей, говорите — и распознанный текст оказывается в том
приложении, где вы работали. Распознавание идёт либо **целиком на вашем Mac** — Whisper
или Parakeet через Neural Engine, без интернета и без ключа, — либо через любой
OpenAI-совместимый сервис. DOKA живёт в строке меню и не занимает места в Dock.

Интерфейс локализован на русский и английский; код и комментарии написаны по-русски.

## Возможности

- **Голосовая диктовка** — глобальный хоткей (или push-to-talk, или кнопка мыши) → запись →
  транскрипция → автозамены по словарю → вставка текста в активное приложение через буфер
  обмена и синтетический ⌘V.
- **Плавающая панель записи** — шесть стилей: `aurora`, `studio`, `classic`, `mini`,
  `notch` (плашка, прирастающая к вырезу камеры) и `hidden`.
- **Транскрибация файлов** — перетащите аудио или видео и получите сегменты с тайм-кодами,
  субтитры (SRT/VTT) и, по желанию, разделение по спикерам. У встроенного сервиса задача
  выполняется асинхронно: она переживает обрыв сети, сон Mac и даже перезапуск приложения —
  результат добирается без повторной загрузки файла и повторной оплаты.
- **Недавние транскрибации** — локальный журнал выполняющихся и готовых задач. Готовые
  открываются обратно со всеми экспортами и сменой детализации тайм-кодов.
- **ИИ-анализ расшифровки** — протокол встречи, краткое резюме, список задач или свой
  запрос. Результат рендерится как оформленный текст с заголовками, списками и таблицами;
  копирование кладёт в буфер и обычный текст, и форматированный — в Telegram, Notes или
  Word таблицы вставляются таблицами.
- **История** — журнал диктовок с метаданными, воспроизведением записи, экспортом
  (CSV или текст) и экраном анализа производительности.
- **Дашборд** — сколько слов надиктовано, сколько времени сэкономлено и во сколько раз это
  быстрее вашей собственной печати (измеряется встроенным тестом), плюс график по дням.
- **Обработка звука** — буст громкости микрофона на время записи, удаление тишины перед
  отправкой и системные звуки ключевых переходов.
- **Словарь** — регистронезависимые правила автозамены, применяемые к каждой расшифровке.

## Приватность

Три режима распознавания отличаются тем, что покидает ваш Mac:

| Режим | Что уходит с вашего Mac |
|---|---|
| Локальные модели (Whisper, Parakeet) | **Ничего.** Звук не покидает устройство, ключ не нужен |
| Встроенный сервис (Nexara) | Аудио загружается на `api.nexara.ru` для распознавания |
| Свой OpenAI-совместимый сервис | Аудио загружается на указанный вами адрес |

Всё остальное остаётся локальным. История расшифровок, статистика и журнал транскрибаций
лежат в `~/Library/Application Support/DOKA`. Сохранение аудио диктовок **по умолчанию
выключено**; если включить, записи хранятся локально в m4a и удаляются по выбранному сроку.
Ключи API живут в Keychain macOS, а не в файлах настроек.

## Требования

- macOS 14 (Sonoma) или новее.
- Apple Silicon для локальных моделей. Whisper работает и на Intel, но заметно медленнее;
  Parakeet — только на Apple Silicon.
- Swift 5.9+ (Xcode 15 или новее) для сборки из исходников.
- Ключ API — только если выбран облачный сервис; локальным моделям он не нужен.

## Установка

Подписанного релиза пока нет, поэтому собираем из исходников:

```bash
git clone https://github.com/ippitenin/DOKA.git
cd DOKA/DOKA-app
./build.sh
```

Приложение устанавливается в `~/Applications/DOKA.app`. При первом запуске macOS попросит
доступ к **микрофону** и **универсальному доступу** (Accessibility): первый нужен для
записи, второй — для вставки текста.

## Сборка и подпись

Все команды выполняются из `DOKA-app/`:

```bash
swift build        # быстрая проверка компиляции (debug)
./build.sh         # release (universal: arm64 + x86_64), подпись, установка в ~/Applications
./build.sh --dmg   # то же + DOKA.dmg в корне репозитория
./run.sh           # build.sh + запуск приложения
```

Release подписывается самоподписанным сертификатом **«DOKA Dev»** — инструкция в
[`DOKA-app/scripts/make-dev-cert.md`](DOKA-app/scripts/make-dev-cert.md). Имя сертификата и
папку установки можно переопределить переменными `DOKA_SIGN_ID` и `DOKA_INSTALL_DIR`.

При установке с DMG на другом Mac сертификат системе неизвестен, и Gatekeeper заблокирует
первый запуск: Системные настройки → «Конфиденциальность и безопасность» → **«Открыть всё
равно»**, затем выдать разрешения микрофона и Accessibility.

## Сервисы распознавания

Выбираются в разделе **«Сервис»**:

| Сервис | Ключ API | Особенности |
|---|---|---|
| Whisper Large v3 Turbo (Local) | не нужен | разовая загрузка ~1,6 ГБ, работает через WhisperKit на Neural Engine |
| Parakeet TDT 0.6B v3 (Local) | не нужен | ~1 ГБ, работает через FluidAudio, только Apple Silicon |
| Встроенный (Nexara) | нужен | добавляет диаризацию, роли спикеров, ИИ-анализ и async-режим |
| Свой сервис | нужен | любой OpenAI-совместимый эндпоинт `/audio/transcriptions` |

Локальные модели скачиваются один раз в разделе «Сервис», при первом использовании
готовятся под ваш чип и выгружаются из памяти после пяти минут простоя. Диаризация, роли
спикеров и ИИ-анализ — расширения встроенного сервиса, у остальных они скрыты: у обычного
OpenAI-совместимого API таких полей нет, а `prompt` там означает совсем другое.

## Разработка

Архитектура, инварианты, команды и гейты верификации описаны в [`CLAUDE.md`](CLAUDE.md).
Коротко: центральный конечный автомат — `DictationController`; транскрибация файлов
намеренно изолирована от пайплайна диктовки (`FileTranscriptionController` и
`Network/FileTranscriptionClient.swift`); дизайн-система — в `UI/DesignSystem/`.

Автоматических тестов нет. Вместо них: сборка без предупреждений, `plutil -lint` обоих
файлов `Localizable.strings`, release-сборка с подписью и ручной smoke по затронутым
областям. Чистая логика написана тестопригодно и проверяется вне приложения.

Две вещи, которые стоит знать до правок зависимостей и строк:

- **Не поднимайте WhisperKit выше линии 0.18.x** — в 1.x два executable-продукта делят
  таргет, и universal-сборка падает с «duplicate key found».
- **Каждая строка интерфейса идёт через `L("ключ")`**, и ключ обязан быть в обоих файлах —
  `ru.lproj` и `en.lproj`. `swift build` синтаксис `.strings` не проверяет, после правок
  прогоняйте `plutil -lint`.

Вклады приветствуются — см. [`CONTRIBUTING.ru.md`](CONTRIBUTING.ru.md).
